# Portfolio (scaffold)

This repository now contains a responsive single-page portfolio scaffold using Tailwind via the CDN. It's designed to be edited directly and deployed on GitHub Pages.

Quick notes:

- Files added:
  - `index.html` — main site
  - `src/styles.css` — small custom styles
  - `src/main.js` — small JS for mobile nav and contact form behavior

- Images use placeholders from https://placehold.co. Replace them with your own images in an `assets/` folder and update paths.
- To add a resume, upload `assets/resume.pdf` and update the resume download link in `index.html`.

Deploying on GitHub Pages:
1. Go to the repository Settings → Pages.
2. Set Branch to `main` and Folder to `/ (root)` and save.
3. After a minute, your site will be available at `https://<your-username>.github.io/<repo-name>/`.
